Student Average Calculator
A lightweight Java console application designed to calculate student averages and determine academic performance metrics. This tool simplifies grade tracking by processing multiple subject scores to output a final average.

🚀 Features
Dynamic Subject Entry: Input marks for any number of courses or subjects.

Total & Average Calculation: Automatically computes the sum of all marks and calculates the overall average percentage.

Performance Assessment: Evaluates the final average to determine passing status or performance classifications.

Clean CLI Output: Displays a clear, structured breakdown of the results directly in the console.

🛠️ Tech Stack
Language: Java (JDK 8 or higher)

Input Handling: java.util.Scanner

📊 How It Works
Input: The application prompts the user to enter the total number of subjects.

Processing: The user inputs the score for each individual subject.

Output: The system aggregates the data and prints out:

Total Marks Obtained

Final Average Percentage

Pass/Fail or Grade classification
